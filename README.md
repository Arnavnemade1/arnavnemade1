### 🛠️ Featured Systems

#### [Arc](https://github.com/arnavnemade1) — Universal Multi-Agent Platform
*3rd Place Overall & MorphLLM Track Finalist — Y Combinator Hackathon*
- Engineered a real-time agent coordination architecture where specialized autonomous agents (CTO, backend engineer, UI designer, CFO) collaborate synchronously in a Slack-like environment to scaffold startup MVPs.
- Implemented peer-review debate protocols and consensus arbitration for automated architectural decision-making.
- **Tech:** TypeScript, Next.js, Vercel, Realtime Multi-Agent Protocols

#### [AegisOS](https://github.com/arnavnemade1) — Verified Clinical Triage OS & Sepsis Predictor
- Built a zero-trust clinical communication kernel where every triage routing decision is formally proved against **6 hospital-policy safety invariants** using the **Z3 Theorem Prover** prior to dispatch.
- Trained a stacked-ensemble sepsis detector on 24,206 patient records, achieving 0.800 AUROC on 6,852 held-out patients (ECE 0.003) and 0.68–0.70 cross-hospital AUROC.
- Architected with a kernel syscall gate, hash-chained audit journal, 160 API endpoints, and 91 verification suites injecting known failure modes. Research use only.
- **Tech:** Python, FastAPI, Z3 Theorem Prover, Next.js, Supabase, PyTorch

#### [Ace](https://github.com/arnavnemade1) — Autonomous Financial Trading Swarm
*Selected for OpenAI Outskill Hackathon (Top 100 Teams)*
- Deployed a swarm of 8–12 specialized LLM agents (data scout, energy analyst, risk sentinel, executor) that debate and vote on trade allocations with fully auditable reasoning traces.
- Built a nightly **Causal Replay Arena** that replays 24-hour market tape against live trade predictions to iteratively refine causal graphs.
- Live dashboard with agent observatory, portfolio risk limits, and paper execution via Alpaca.
- **Tech:** TypeScript, Alpaca API, Causal Graph Modeling, Discord Automation

#### [Splice](https://github.com/arnavnemade1) — Web-to-Semantic-Stream MCP Server
- High-throughput Model Context Protocol (MCP) server transforming real-time web streams into structured, grounded semantic context for autonomous agent workflows to minimize hallucinations.
- **Tech:** TypeScript, Model Context Protocol (MCP), Streaming Ingestion
